# 拾忆界面设计系统

## 产品与视觉方向

- 产品类型：个人记忆与行动管理工具
- 核心体验：先记录，再凭线索找回，并让值得行动的内容重新出现
- 视觉主题：安静的个人档案室
- 设计取向：内容优先、清晰留白、轻量层次、少量暖色提示
- 设计参数：变化度 4/10，动效 3/10，密度 4/10

## 颜色

| 角色 | 色值 | 用途 |
|---|---|---|
| 深墨绿 | `#0E2922` | 主文字、主按钮 |
| 档案绿 | `#176B55` | 当前状态、链接、焦点 |
| 深绿侧栏 | `#15382F` | 固定导航 |
| 淡薄荷 | `#E7F2ED` | 选择状态、标签 |
| 画布 | `#F5F8F6` | 页面背景 |
| 纸白 | `#FFFFFF` | 编辑器、详情页、卡片 |
| 暖橙 | `#D69A63` | 少量强调，不承担唯一状态含义 |
| 危险红 | `#A94640` | 删除操作 |

正文与主要操作的对比度以 4.5:1 为最低目标。状态不只依靠颜色表达。

## 字体与排版

- 中文使用系统无衬线字体，英文和数字优先使用 Inter。
- 正文字号不低于 16px；常用标签不低于 14px；仅次要元信息可使用 12至13px。
- 标题强调清楚的字重和行距，不使用大面积超粗字。
- 长链接和长标题必须允许安全换行或省略，并提供完整查看入口。

## 布局

- 左侧导航固定，但不得遮挡内容。
- 首页首屏直接露出记录输入区，不设置营销式大首屏。
- 全部记忆、找回、行动、再见、回收站使用完整工作页面。
- 桌面端内容宽度约 1040px；移动端保留 14至22px 页面边距。
- 间距遵循 4/8px 节奏，主要层级使用 16、24、32、48px。

## 组件

- 按钮和可点击目标至少 44×44px。
- 侧栏当前页面必须有文字、底色和装饰条三重反馈，并设置 `aria-current`。
- 输入框必须有可见标签，错误显示在对应操作附近。
- 保存操作显示加载状态，成功后关闭编辑页并给出提示。
- 图片缩略图可点击放大；大图使用可关闭的模态框，并支持键盘焦点。
- 图标统一使用线性 SVG，不使用 emoji 充当结构图标。

## 动效

- 交互过渡使用 160至220ms，主要用于颜色、边框和阴影。
- 避免会推动周围布局的缩放动效。
- 尊重 `prefers-reduced-motion`，减少模式下去除非必要位移和动画。

## 上线前检查

- 375px、768px、1024px、1440px 宽度下没有横向滚动或文字裁切。
- 所有键盘焦点清晰可见。
- 固定侧栏不遮挡页面与弹窗。
- 侧栏切换无需先关闭当前内容页。
- 图片预览、详情图片放大、保存后返回都能正常工作。
